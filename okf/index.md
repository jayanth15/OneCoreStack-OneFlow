# OneFlow — OKF Knowledge Bundle

OneFlow is a single-tenant ERP system for small-to-medium manufacturing businesses, covering inventory, production planning, job card tracking, scheduling, procurement, dispatch, gate passes, GRN, and unified request management.

## Domains

- [Architecture](/architecture.md) — System overview and technology stack
- [Auth System](/auth/auth-system.md) — Authentication, authorization, user management
- [Inventory System](/inventory/inventory-system.md) — All inventory types (raw materials, finished goods, consumables, spares, weeders, attachments)
- [Production System](/production/production-system.md) — BOM, schedules, production plans, job cards, work types
- [Procurement System](/procurement/procurement-system.md) — Vendors, suppliers, purchase orders, GRN
- [Request System](/requests/request-system.md) — Unified request lifecycle (internal transfer, vendor purchase, customer dispatch)
- [Logistics System](/logistics/logistics-system.md) — Dispatch, gate passes, receipts
- [API Endpoints](/endpoints/api-endpoints.md) — All backend REST API endpoints
- [Frontend Architecture](/frontend/frontend-architecture.md) — Next.js frontend pages, components, layout
- [Deployment](/operations/deployment.md) — Setup, startup scripts, environment configuration
